# 远离这两大“女性杀手”，谢凤云副主任呼吁：两癌筛查做起来！

> 更新时间：2026-09-11 (UTC+8)

对于女性来说

最可怕的就是

**乳腺癌和宫颈癌**

这两大威胁生命的“杀手”

乳腺癌和宫颈癌在女性恶性肿瘤中分居第一、二位,且近年有增高趋势。中国抗癌协会数据显示,我国子宫颈癌患病率和死亡率占世界三分之一,也是上升速度最快的癌种之一。

然而，宫颈癌在零期以前的治愈率几乎为100%,是目前唯一可以早期预防和治疗的癌症。

**因此，癌症不可怕，关键要早查！**

 

**什么是“两癌”筛查?**

“两癌”指的是宫颈癌和乳腺癌。

"两癌 "筛查就是指通过先进的检查手段,排查出受检者是癌症还是一般的妇科疾病。

**“两癌”筛查的目的是什么?**

将这两种危害妇女健康的癌症,尽早排查出来,做到**早诊断、早发现、早预防、早治疗**。

**“两癌"筛查项目有哪些？**

宫颈癌：妇科常规检查、宫颈脱落细胞学检查、宫颈人乳头瘤病毒检查、阴道镜检查、组织病理学检查。

乳腺癌：乳腺临床检查、乳腺彩超、钼靶— X 线检查。

 

**“两癌”筛查的检查对象是谁？**

所有25-64岁的适龄女性。

 

**“两癌”筛查有什么注意事项？**

1.不是所有受检者参加所有的检查项目。

（1）宫颈癌筛查：所有受检者进行妇科常规检查和人乳头瘤病毒（HPV）检测, HPV检测阴性者，将检查结果反馈给受检者，本次筛查即完成。

HPV检测有感染者，根据HPV分型，进行宫颈细胞学检查或者阴道镜检查,阴道镜正常者3年后进行筛查,异常或可疑者进行组织病理学检查。

（2）乳腺癌筛查：所有受检者进行乳腺临床触诊和乳腺彩超检查,无异常者将检查结果反馈给受检者，本次筛查即完成。有异常或可疑者进行钼靶— X 线检查。钼靶— X 线检查异常或可疑者进行病理诊断。

2.乳腺检查要注意避开经前期。

宫颈癌HPV检测、宫颈脱落细胞学检查前48小时不能性交、阴道冲洗和上药,要避开月经期。

阴道镜检查48小时之内不宜进行妇科检查、细胞学刮片、阴道冲洗、上药、性交等,最好选择在月经干净后3-4天进行检查。
