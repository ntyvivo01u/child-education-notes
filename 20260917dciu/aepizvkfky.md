# 【论坛】第四届同济大学泌尿肿瘤高峰论坛圆满举行

> 更新时间：2026-09-17 (UTC+8)

2019年11月30日至12月1日，第四届同济大学泌尿肿瘤高峰论坛暨2019上海市医学会泌尿外科分会肿瘤学组会议在上海市第十人民医院隆重举行。此次会议的召开标志着全国泌尿外科学界同道对上海十院泌尿外科近年来的临床与科研工作的肯定与支持！

上海市第十人民泌尿外科主任姚旭东教授作为大会主席并担任主持。在开幕式上，姚旭东教授感谢各位专家同行对十院泌尿外科的发展的关心和关注，上海十院泌尿外科全体医护人员始终不忘初心，不懈奋斗！海军军医大学孙颖浩院士，同济大学附属第十人民医院范理宏书记，上海市医学会泌尿外科分会郑军华主任委员，同济大学医学院郑加麟院长，出席会议并分别致欢迎辞。

**姚旭东教授主持开幕式**

**孙颖浩院士致欢迎辞**

**郑军华主任委员致欢迎辞**

**范理宏书记致欢迎辞**

**郑加麟院长致欢迎辞**

在院士论坛环节中，孙颖浩院士首先以《5G时代，外科医生的机遇与挑战》为题，结合不断革新的技术突破，就泌尿外科未来发展指出了方向，引起与会学者的热烈讨论。

在大师专题中，上海市第一人民医院的郑军华教授，海军军医大学长海医院的许传亮教授，中国医学科学院肿瘤医院邢念增教授，美国约翰霍普金斯大学的罗军教授，上海交通大学医学院附属仁济医院的黄翼然教授，海军军医大学长征医院的王林辉教授，来自德国图宾根大学的Arnulf Stenzl教授等国内外的知名专家教授分别介绍了前列腺癌、膀胱癌、肾癌的基础和临床研究的最新进展和成果。

在泌尿肿瘤手术技术及技巧方面，来自北京大学第一医院的张骞教授，浙江大学附属第一医院的夏丹教授，北京航空中心医院的张保教授与参会同道交流了自己长期以来的经验和体会。会议还涉及了近年来热门的基因检测技术在泌尿外科中的应用，来自上海交通大学医学院附属仁济医院的董柏君教授，来自海军军医大学长海医院的李晶教授分别就基因检测的现状和在泌尿肿瘤中的临床应用谈了自己的经验和体会。上海十院放射科赵炳辉教授，也就最新的影像学技术在泌尿系统肿瘤中的临床应用前景做了介绍。

**现场手术演示**

周六会议的一大特色是安排了精彩丰富的泌尿外科手术演示，共同提高临床治疗规范、突破难点与切磋技巧。

张骞教授、崔心刚教授、徐丹枫教授、刘春晓教授、王少刚教授、李东教授等多位国内顶尖专家应邀在十院手术室进行手术演示，内容包括5台前列腺癌根治术，3台经皮肾镜碎石术，2台经尿道前列腺钬激光剜除术。

十院泌尿外科3位专家也同场竞技，献上了精彩的手术演示，姚旭东教授演示了开放前列腺癌根治术、彭波教授演示了3D腹腔镜下前列腺根治、许云飞教授演示了经皮肾镜碎石术。精彩的手术赢得了在场观众的阵阵掌声，充分展示了十院的技术和风采。

**学术演讲**

周日的会议中，着重讨论泌尿肿瘤的基础和转化研究，来自德国图宾根大学的Arnulf Stenzl教授，同济十院范理宏教授，中科院上海营养与健康研究院的秦骏教授，上海交通大学医学院的高维强教授等在泌尿肿瘤基础研究中卓有建树的专家分别介绍了各自领域的最新科研成果和研究前景。

会议还设置了护理专场，来自同济十院的护理部的陈翠萍教授，上海交通大学医学院附属仁济医院的孟晓红教授，复旦大学附属中山医院的崔蓉教授，十院泌尿外科刘永珍和贺徐琳护士长分别对泌尿外科护理的教学，临床和管理做了精彩的汇报。

本次会议吸引了来自国内外400多名学者参加。大会的成功举办标志着科室发展进入了新的高度，广大同仁将以此为契机，开拓进取，继续打造上海十院泌尿外科的新品牌。
